> **文档版本：** v1.0
> **更新日期：** 2026-04-29
> **状态：** 草稿

---

## 1. 文档概述

### 1.1 产品简介

美容店管理系统（以下简称"系统"）是一套面向美容连锁门店的数字化经营管理系统，涵盖会员管理、预约管理、充值消费、活动营销、库存管理等核心业务模块。系统支持 PC Web 端和移动端（H5/小程序）多端访问，旨在提升门店运营效率、优化顾客体验、实现精准营销。

### 1.2 目标用户

| 用户角色 | 说明 |
|---|---|
| 门店管理员 | 负责门店整体运营，包括财务、员工、排班、数据报表 |
| 美容师 | 查看预约、服务记录、自己的客户档案 |
| 前台/接待 | 会员登记、预约确认、收银、消费记录 |
| 顾客 | 通过移动端在线预约、查看积分余额、参与活动 |

### 1.3 名词定义

| 术语 | 定义 |
|---|---|
| 会员等级 | 根据累计消费金额或积分划分的用户级别，不同等级享有不同折扣 |
| 积分 | 顾客消费后获得的奖励积分，可用于抵扣现金或兑换礼品 |
| 充值赠送 | 顾客充值时，商家额外赠送的余额或积分 |
| 疗程卡 | 包含固定次数服务的预付费卡（如"面部护理10次卡"） |
| 排班 | 美容师的工作时间安排，决定可预约时段 |

## 2. 功能需求

### 2.1 会员管理

#### 2.1.1 会员注册

- **线下注册**：前台通过系统录入会员信息，包括姓名、手机号、生日、性别、职业、来源渠道等
- **线上注册**：顾客通过小程序/H5自主注册，系统发送验证码完成手机号验证
- **注册礼**：新会员注册成功后自动发放新人礼包（含积分/优惠券）
- **会员档案**：每位会员拥有独立档案页，展示基本信息、等级、余额、积分、消费记录等

#### 2.1.2 会员等级

| 功能 | 描述 |
|---|---|
| 等级定义 | 支持自定义等级名称、等级图标、升级条件（累计消费金额/积分门槛） |
| 等级数量 | 至少支持 5 个等级（如：普通、银卡、金卡、钻卡、VIP） |
| 等级权益 | 每个等级配置独立折扣比例（服务/产品）、积分倍率、生日礼遇 |
| 升级规则 | 累计消费金额达到阈值自动升级，支持手工调整等级 |
| 降级规则 | 支持设置保级周期（如：1年内累计消费未达门槛则降一级） |

#### 2.1.3 积分管理

- **积分获取**：消费得积分（按实际支付金额×等级积分倍率计算）、活动奖励、签到奖励
- **积分使用**：积分抵现（100积分=1元，可设置最低抵扣门槛）、积分兑换礼品、积分抽奖
- **积分明细**：每条积分变动记录可查询（来源/使用/过期/清零）
- **积分规则**：支持按服务项目或产品设置不同的积分获取比例

#### 2.1.4 消费记录

- **消费流水**：每笔消费生成唯一订单号，记录顾客、门店、美容师、项目/产品、数量、实付金额、支付方式、使用积分、优惠内容
- **消费小票**：支持打印小票，内容包含门店信息、商品明细、支付信息
- **历史查询**：支持按时间段、会员姓名/手机号、美容师、门店筛选消费记录
- **关联预约**：消费记录与预约记录一一对应，支持双向跳转查看

---

### 2.2 预约管理

#### 2.2.1 在线预约

- **预约入口**：顾客通过小程序/H5发起预约
- **选择服务**：顾客选择服务项目（支持单项目或多项目组合）
- **选择美容师**：顾客可指定美容师，或由系统自动分配空闲美容师
- **选择时间**：展示可预约时段（基于美容师排班和已有预约），禁止超约
- **预约确认**：预约成功后发送短信/小程序消息提醒；支持管理员/前台代为创建预约
- **取消/改期**：顾客可在预约时间前N小时（如2小时）免费取消或改期；超时未到自动标记为"爽约"
- **候补预约**：预约满时顾客可加入候补队列，有取消时自动通知候补顾客

#### 2.2.2 预约日历

- **日历视图**：以日为视图单位，展示所有预约的分布情况
- **色块区分**：用颜色区分预约状态（待确认/已确认/服务中/已完成/已取消/爽约）
- **筛选功能**：按门店、美容师、服务项目、日期范围筛选
- **拖拽调整**：管理员可拖拽调整预约时间或美容师（需校验排班冲突）
- **候诊队列**：展示当前等候中的顾客列表

#### 2.2.3 预约提醒

| 提醒类型 | 触发时机 | 触达方式 |
|---|---|---|
| 预约成功通知 | 预约创建时 | 短信 + 小程序消息 |
| 预约前一天提醒 | 预约时间前24小时 | 短信 + 小程序消息 |
| 预约当日前提醒 | 预约时间前1小时 | 小程序消息 |
| 美容师工作提醒 | 美容师排班开始前 | 系统内推送 |

#### 2.2.4 美容师排班

- **排班模板**：支持按周设置排班模板，快速复用到多周
- **排班维度**：按门店+美容师+星期设置上班/休息/请假
- **工作时段**：设置每日工作时间（如09:00-18:00）及午休时间
- **临时调整**：支持临时调班（需双方确认）、请假的操作
- **排班冲突检测**：同一美容师同一时段不能同时安排两项服务
- **美容师可用时段**：自动根据排班和已有预约计算实时可用时段

### 2.3 充值管理

#### 2.3.1 余额充值

- **充值档次**：管理员设置多档充值金额（如：500/1000/2000/5000元）
- **自定义金额**：支持顾客输入任意金额充值（设置最低/最高限额）
- **支付方式**：支持现金、银行卡、微信、支付宝、信用卡等
- **充值凭证**：记录支付凭证号，支持退款时核对

#### 2.3.2 充值赠送

| 赠送类型 | 规则示例 |
|---|---|
| 满送赠送 | 充值满1000元送100元，满2000元送300元 |
| 比例赠送 | 充值金额的10%作为赠送金 |
| 积分赠送 | 充值即赠送对应积分（按充值金额计算） |
| 阶梯赠送 | 充值越多赠送比例越高（分档计算） |

- **赠送到账**：赠送金额/积分实时到账，支持设置赠送金的有效期
- **赠送金规则**：赠送金不可提现，消费时优先扣除赠送金

#### 2.3.3 消费扣款

- **扣款优先级**：消费时优先扣除赠送金，再扣除本金余额
- **余额不足提醒**：余额不足以完成支付时，提示顾客充值或选择其他支付方式
- **消费流水**：每次扣款生成消费流水，记录扣款前余额、扣款金额、剩余余额
- **退卡/退款**：支持会员申请退卡退款，扣除已消费金额后返还剩余本金（赠送金不退）

### 2.4 活动管理

#### 2.4.1 打折满减活动

| 活动类型 | 规则说明 |
|---|---|
| 限时折扣 | 指定时间段内，某服务/产品享受N折（如：春节期间面部护理8折） |
| 满额满减 | 消费满X元减Y元（可设置上限，如满300减30、满500减60） |
| 满件折扣 | 购买指定数量享受折扣（如：买3件面膜享7折） |
| 组合套餐 | 将多个服务/产品打包为套餐，以套餐价销售 |
| 第二件半价 | 指定产品第二件享半价优惠 |

- **活动时段**：设置活动开始时间、结束时间，支持重复（如：每周五会员日）
- **叠加规则**：设置活动是否可与其他优惠叠加（积分、优惠券、会员折扣等）
- **适用门店**：可指定活动适用于哪些门店（单店/部分/全部门店）
- **适用人群**：可限制活动仅对特定会员等级开放

#### 2.4.2 优惠券

| 类型 | 说明 |
|---|---|
| 满减券 | 消费满X元可用（设置门槛和优惠金额） |
| 折扣券 | 指定服务/产品享受X%折扣 |
| 现金券 | 抵扣固定金额（如：代金券50元） |
| 项目体验券 | 限指定服务项目免费体验一次 |

- **发放方式**：管理员手动发放、顾客自助领取（需设置领取门槛）、注册/消费/活动自动发放
- **核销规则**：设置有效期（固定日期/领取后N天）、每人限领数量、适用服务/产品
- **使用记录**：每张优惠券记录发放对象、发放时间、使用时间、使用订单

#### 2.4.3 效果统计

- **活动概况**：展示活动的曝光量、领取量、核销量、优惠金额、直接带来的销售额
- **ROI分析**：计算活动投入（优惠金额）与产出（带来的销售额）的比值
- **参与明细**：列出参与活动的顾客列表、消费时间、消费金额
- **对比分析**：对比活动期间与活动前/后的同期数据（客单价、客单量、营业额等）
- **数据导出**：支持将统计数据导出为Excel

### 2.5 基础数据

#### 2.5.1 服务项目管理

- **服务项目**：名称、分类（面部/身体/美甲/脱毛等）、单价、时长、所需耗材、适用美容师
- **项目状态**：在售/停售/隐藏
- **关联美容师**：设置哪些美容师可以操作该项目（影响预约时的美容师可选列表）
- **服务流程**：支持为项目配置标准服务流程步骤（用于培训或SOP展示）

#### 2.5.2 产品库存管理

- **产品信息**：名称、分类、规格、单位、零售价、会员价、成本价、供应商
- **库存管理**：支持多仓库/多门店库存独立管理，入库/出库/盘点功能
- **库存预警**：设置最低库存量，低于预警值时系统提醒
- **产品批次**：记录生产日期、保质期、批次号（用于临期预警）
- **出入库流水**：每笔出入库操作记录操作人、时间、数量、备注
- **产品条码**：支持扫码快速查找产品

#### 2.5.3 美容师管理

- **美容师档案**：姓名、工号、性别、手机号、照片、入职日期、擅长领域、技能等级
- **技能标签**：如"资深面部护理"、"美甲专家"，便于顾客和系统匹配
- **绩效统计**：按月/季/年统计美容师的预约量、好评率、服务时长、销售额
- **资质证书**：上传美容师资质证书图片（合规经营需要）

#### 2.5.4 门店管理

- **门店信息**：门店名称、地址、联系电话、营业时间、经纬度（用于地图展示）
- **门店角色**：设置为总店或分店；总店可查看所有分店数据，分店仅可见本店数据（按权限）
- **门店配置**：单独设置每个门店的营业时间、预约上限、节假日特殊安排

### 2.6 用户角色与权限

#### 2.6.1 角色定义

| 角色 | 可用功能范围 |
|---|---|
| **超级管理员** | 全系统功能，可管理所有门店和所有用户 |
| **门店管理员** | 本门店的全部运营功能，包括报表、员工管理 |
| **美容师** | 自己的预约日历、服务记录、自己的客户列表、绩效查看 |
| **前台/接待** | 会员注册/查询、预约管理（创建/确认）、收银、消费记录 |
| **财务** | 财务报表、充值记录、退款审批、资金流水 |
| **顾客** | 移动端：预约、查看档案、余额积分、优惠券、参与活动 |

#### 2.6.2 权限配置

- 超级管理员可自定义角色和权限颗粒度（如：某角色是否可以退款、是否可以导出数据）
- 权限维度：菜单级权限 + 操作级权限（如：可查看报表 vs 可导出报表）
- 敏感操作需二次验证（如：退款、退卡、删除数据）

## 3. 非功能需求

### 3.1 移动端支持

- **小程序/H5**：面向顾客端（预约、查余额积分、看活动、下单）
- **移动端管理后台**：面向门店员工的轻量级管理工具（预约确认、会员查询、收款）
- **响应式设计**：页面自适应手机屏幕，操作流畅
- **消息推送**：支持微信服务号/小程序订阅消息、短信通知
- **离线缓存**：预约日历等页面支持离线查看最近数据

### 3.2 权限与安全

- **身份认证**：用户需通过账号密码登录；顾客端支持手机号验证码登录
- **Token机制**：API 接口使用 JWT Token 认证，设置合理有效期
- **数据权限**：严格按角色和门店隔离数据，防止越权访问
- **密码策略**：至少8位，支持字母+数字组合，定期提示修改
- **敏感数据加密**：会员手机号、身份证号等敏感信息加密存储
- **操作日志**：记录所有用户的登录日志和关键操作日志（时间、操作人、操作类型、操作对象、操作前后数据）
- **日志保留**：操作日志至少保留3年
- **日志审计**：支持按时间范围、操作人、操作类型查询日志

### 3.3 系统日志

| 日志类型 | 内容 |
|---|---|
| 登录日志 | 用户登录/登出时间、IP地址、设备信息 |
| 操作日志 | 会员管理、预约变更、充值退款、库存变动等操作 |
| 系统日志 | 定时任务执行、接口调用异常、数据备份等 |
| 安全日志 | 密码错误、权限越界、异常IP访问 |

- 日志仅管理员可查，不可被业务人员修改或删除
- 支持按条件筛选和导出

### 3.4 性能与可用性

- 系统支持 99.5% 以上的可用性（每月停机时间不超过3.6小时）
- 页面平均加载时间不超过3秒，API 接口响应时间不超过500ms（P95）
- 支持单门店200+同时在线用户；SaaS版本支持跨门店总体高并发
- 数据定期备份（每日全量备份 + 实时增量备份），支持7天内任意时间点恢复

### 3.5 扩展性与兼容性

- 支持多语言（目前默认中文，后续可扩展英文/日文等）
- 开放 API 接口文档，支持与第三方POS、美团、大众点评等平台对接
- 支持打印设备（小票打印机、标签打印机）集成

## 5. 业务流程汇总

### 5.1 会员消费完整流程

```
新客注册 → 预约服务 → 到店确认 → 美容师接单 → 服务完成 → 收银结算（余额/现金/混合） → 积分累计 → 会员升级判断 → 发送评价邀请
```

### 5.2 充值完整流程

```
选择充值金额 → 确认赠送方案 → 支付（扫码/现金） → 充值到账 → 发送通知 → 记录流水
```

### 5.3 活动执行流程

```
创建活动（设置规则/时间/范围） → 活动上线 → 顾客参与（领取/下单） → 核销使用 → 效果统计
```

## 6. 优先级说明

| 优先级 | 模块 |
|---|---|
| P0（核心必须） | 会员管理、预约管理、充值消费、收银结算 |
| P1（重要） | 活动管理（打折/优惠券）、美容师排班、提醒通知 |
